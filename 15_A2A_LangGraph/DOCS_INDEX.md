## 🔍 Quick Reference

### Commands

```bash
# Start server
uv run python -m app

# Run client (interactive)
uv run python app/run_client_agent.py -i

# Run client (single query)
uv run python app/run_client_agent.py -q "your query"

# Run tests
uv run python test_client_agent.py

# Visualize graph
uv run python app/visualize_client.py
```
